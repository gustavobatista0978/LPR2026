# Confirmação de Clone do Repositório

## Descrição

Este programa em C++ exibe uma mensagem de confirmação visual em terminal, simulando o clone de um repositório para o ambiente local.

---
## Como funciona

1. O programa usa caracteres de formatação para criar uma interface visual.
2. A mensagem mostra que o repositório foi clonado com sucesso.
3. O código utiliza cores e bordas para deixar a saída mais amigável.
4. A tela final exibe a mensagem de parabéns.
