# Verificação de Números Múltiplos

## Descrição

Este programa em C++ verifica se dois números inteiros digitados pelo usuário são múltiplos entre si.

O usuário digita dois valores inteiros, e o programa utiliza o operador de resto da divisão (`%`) para verificar se um número é divisível pelo outro.

Depois disso, o resultado é exibido informando se os números são múltiplos ou não.

---
## Como funciona

1. O programa pede ao usuário dois valores inteiros.

2. Os valores digitados são armazenados nas variáveis `A` e `B`.

3. O programa verifica se `A` é divisível por `B`.

4. O programa verifica se `B` é divisível por `A`.

5. Caso uma das divisões tenha resto igual a `0`, os números são considerados múltiplos.

6. O resultado é mostrado na tela.
