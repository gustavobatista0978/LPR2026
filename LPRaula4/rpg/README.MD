# Escolha de Classe em um RPG

## Descrição

Este programa em C# simula a escolha de uma classe em um jogo de RPG.

O usuário escolhe uma opção entre Guerreiro, Mago ou Arqueira, digitando um número correspondente.

Depois disso, o programa exibe informações sobre a classe escolhida. Caso seja digitada uma opção inválida, uma mensagem de erro é apresentada.

---
## Como funciona

1. O programa exibe uma mensagem de boas-vindas ao RPG.

2. São mostradas três opções de classe:
   - `1` para Guerreiro  
   - `2` para Mago  
   - `3` para Arqueira  

3. O usuário digita a opção desejada.

4. O programa utiliza a estrutura `switch` para verificar a escolha feita.

5. Uma descrição da classe escolhida é exibida na tela.

6. Caso a opção digitada não exista, o programa informa que a escolha é inválida.
