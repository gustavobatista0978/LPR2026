# Verificação de Número Par ou Ímpar

## Descrição

Este programa em C# verifica se um número inteiro informado pelo usuário é par ou ímpar.

O usuário digita um número inteiro, e o programa utiliza o operador(`%`) para identificar se o número é divisível por 2.

Depois disso, o resultado é exibido informando se o número é par ou ímpar.

---
## Como funciona

1. O programa pede ao usuário um número inteiro.

2. O valor digitado é armazenado na variável `numero`.

3. O programa verifica o resto da divisão do número por `2`.

4. Se o resto da divisão for igual a `0`, o número é considerado par.

5. Caso contrário, o número é considerado ímpar.

6. O resultado é mostrado na tela.
