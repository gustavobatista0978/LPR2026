# Cálculo de Imposto e Salário Líquido

## Descrição

Este programa em C# recebe o nome e o salário bruto de um funcionário e calcula o imposto cobrado, além do salário líquido final. Também permite aumentar o salário com base em uma porcentagem informada.

---
## Como funciona

1. O programa solicita o nome e o salário bruto do funcionário.
2. A classe `Funcionario` calcula o imposto conforme faixas salariais.
3. O salário líquido é calculado subtraindo o imposto do valor bruto.
4. A porcentagem informada é aplicada ao salário e os dados atualizados são exibidos.
