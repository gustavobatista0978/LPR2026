# Cadastro de Cliente

## Descrição

Este programa em C++ organiza as informações de um cliente, como nome e dados de contato, em uma estrutura simples para armazenar e manipular os valores.

---
## Como funciona

1. O programa cria uma estrutura para representar um cliente.
2. Os dados são lidos e armazenados em memória.
3. A lógica da aplicação organiza e exibe as informações cadastradas.
4. O resultado final mostra os dados do cliente em tela.
