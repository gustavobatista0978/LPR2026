# Cadastro de Livros

## Descrição

Este programa em C++ armazena informações de livros em uma estrutura e exibe os dados cadastrados na tela. O objetivo é praticar o uso de registros e manipulação de dados em memória.

---
## Como funciona

1. O programa define uma estrutura para representar um livro.
2. O usuário informa os dados de cada livro, como título, autor e demais informações relevantes.
3. Os dados são armazenados em um vetor ou estrutura de controle.
4. O programa apresenta os livros cadastrados e seus detalhes.
