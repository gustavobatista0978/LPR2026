# Cadastro de Turma

## Descrição

Este programa em C++ organiza informações de uma turma, como alunos, notas e dados gerais, com foco em manipulação de registros e listas simples.

---
## Como funciona

1. O programa define uma estrutura para representar a turma e seus dados.
2. Os alunos ou informações são cadastrados e armazenados em memória.
3. A lógica do programa organiza e exibe os dados da turma.
4. O resultado final mostra as informações processadas ao usuário.
