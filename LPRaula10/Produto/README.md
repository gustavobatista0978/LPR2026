# Cálculo do Preço Total do Pedido

## Descrição

Este programa em C++ cria um produto e um pedido associado a ele, calculando o valor total com base na quantidade solicitada.

---
## Como funciona

1. O programa define a classe `Produto` com nome e preço.
2. A classe `Pedido` guarda a quantidade e referencia o produto cadastrado.
3. O método `PrecoTotal()` calcula o valor final do pedido.
4. O resultado é exibido na tela com o nome do produto, a quantidade e o total.
