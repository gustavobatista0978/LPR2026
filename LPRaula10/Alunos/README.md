# Cálculo da Média Final do Aluno

## Descrição

Este programa em C# lê a matrícula, o nome e as notas de um aluno e calcula a sua média final. A partir da média, o programa informa se o estudante foi aprovado ou se precisa de prova final.

---
## Como funciona

1. O programa solicita a matrícula, o nome e as notas da prova 1, prova 2 e trabalho.
2. A classe `Aluno` calcula a média usando os pesos definidos para cada avaliação.
3. O método `Final()` verifica quanto o aluno precisa para atingir a média necessária.
4. O resultado é exibido na tela com a média e a situação final.
