# Sistema de Pokémon

## Descrição

Este programa em C# cria uma estrutura de personagens com herança, representando um Pokémon, e demonstra o uso de ataques, itens e evolução de nível.

---
## Como funciona

1. A classe `Personagem` define atributos básicos, como nome, nível e HP.
2. A classe `Pokemon` herda essas características e adiciona tipo e poder especial.
3. O programa instancia um Pokémon e utiliza seus métodos de ataque e uso de item.
4. Ao final, o personagem sobe de nível e a ação é exibida na tela.
