# Cálculo da Área e do Perímetro do Retângulo

## Descrição

Este programa em C# lê a altura e a largura de um retângulo e calcula a sua área e o perímetro.

---
## Como funciona

1. O usuário informa a altura e a largura do retângulo.
2. A classe `Retangulo` realiza os cálculos de área e perímetro.
3. Os valores são processados por métodos específicos.
4. O programa mostra os resultados com duas casas decimais.
