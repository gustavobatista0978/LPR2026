# Multiplicação de Matrizes

## Descrição

Este programa em C# realiza operações com matrizes, incluindo a multiplicação de valores ou a manipulação de dados organizados em linhas e colunas.

---
## Como funciona

1. O programa solicita os elementos das matrizes.
2. Os valores são armazenados em estruturas de matriz.
3. A operação matemática adequada é aplicada para gerar o resultado.
4. A saída mostra a matriz resultante ou o valor final calculado.
