# Sala de Aula em Matriz

## Descrição

Este programa em C# organiza informações de alunos ou dados de uma sala em uma matriz, permitindo armazenar e consultar informações em grupos.

---
## Como funciona

1. O programa define a estrutura de dados necessária para representar a sala.
2. Os dados são inseridos e armazenados em posições da matriz.
3. A lógica percorre esses valores para processá-los.
4. O resultado final mostra as informações organizadas na tela.
