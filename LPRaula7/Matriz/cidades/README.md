# Cadastro de Cidades em Matriz

## Descrição

Este programa em C# trabalha com uma matriz para armazenar e manipular dados relacionados a cidades, como nomes, valores ou informações de localização.

---
## Como funciona

1. O programa define uma estrutura de matriz para guardar os dados.
2. Os valores são informados e armazenados nas posições corretas.
3. A lógica percorre a matriz para processar ou buscar informações desejadas.
4. O resultado final mostra os dados organizados na tela.
