# Manipulação de Números Inteiros em Matriz

## Descrição

Este programa em C# trabalha com uma matriz de inteiros e realiza operações como leitura, busca ou processamento dos valores armazenados.

---
## Como funciona

1. O usuário informa os números inteiros que serão armazenados na matriz.
2. Os dados são guardados em posições específicas da estrutura.
3. O programa percorre a matriz para processar e localizar valores.
4. O resultado final apresenta os dados calculados ou a busca realizada.
