# Cadastro de Notas em Vetor

## Descrição

Este programa em C++ lê notas em um vetor e organiza os dados para processamento, como busca ou apresentação das informações cadastradas.

---
## Como funciona

1. O programa coleta várias notas informadas pelo usuário.
2. Os valores são armazenados em um vetor.
3. O código percorre o vetor para realizar a operação desejada.
4. O resultado é exibido na tela de forma organizada.
