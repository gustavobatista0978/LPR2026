# Pesquisa em Vetor de 10 Números

## Descrição

Este programa em C++ armazena 10 números em um vetor e verifica a presença de um valor informado pelo usuário, exibindo as ocorrências encontradas.

---
## Como funciona

1. O programa lê 10 valores para o vetor.
2. O usuário informa o número que deseja procurar.
3. O código percorre o vetor comparando cada elemento.
4. Os resultados são exibidos mostrando as posições e a quantidade de ocorrências.
