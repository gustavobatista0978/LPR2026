# Cadastro de Alunos da Escola

## Descrição

Este programa em C++ trabalha com a organização de dados de alunos em vetor, permitindo armazenar informações e acessá-las de forma simples.

---
## Como funciona

1. O programa define uma estrutura para representar os dados do aluno.
2. Os valores são lidos e armazenados em um vetor.
3. O laço de repetição percorre os elementos para localizar ou apresentar informações.
4. O resultado final mostra os dados processados na tela.
