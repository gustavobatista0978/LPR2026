# Vetor e Busca de Valores

## Descrição

Este programa em C# trabalha com um vetor e realiza operações de leitura, armazenamento e busca de valores informados pelo usuário.

---
## Como funciona

1. O programa solicita os valores que serão armazenados no vetor.
2. Os dados são guardados em posições específicas.
3. O usuário informa um valor para pesquisa.
4. O algoritmo percorre o vetor e mostra onde o valor foi encontrado.
