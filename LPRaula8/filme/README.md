# Cadastro de Filmes

## Descrição

Este programa em C++ cadastra três filmes, guarda seus dados e identifica qual deles é o mais antigo com base no ano de lançamento.

---
## Como funciona

1. O usuário informa título, diretor, ano e duração de cada filme.
2. Os dados são armazenados em um vetor de estruturas.
3. O programa percorre os elementos para localizar o filme mais antigo.
4. O resultado final mostra os filmes cadastrados e o mais antigo.
