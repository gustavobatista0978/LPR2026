# Cadastro de Heróis e Equipe

## Descrição

Este programa em C# permite cadastrar heróis, selecionar uma equipe e calcular a pontuação total da formação escolhida.

---
## Como funciona

1. O usuário informa nome, poder e pontuação de cada herói.
2. Os dados são armazenados em um vetor de estruturas.
3. O usuário seleciona até três heróis para formar a equipe.
4. O programa exibe a equipe selecionada e a pontuação total.
