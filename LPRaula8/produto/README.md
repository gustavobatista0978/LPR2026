# Cadastro de Produto e Pedido

## Descrição

Este programa em C++ cria um produto e um pedido associado a ele, calculando o preço total com base na quantidade escolhida.

---
## Como funciona

1. O programa define classes para `Produto` e `Pedido`.
2. O usuário informa os dados do produto e a quantidade solicitada.
3. O cálculo do preço total é realizado pelo método da classe `Pedido`.
4. O valor final é exibido na tela.
