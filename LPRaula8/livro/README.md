# Cadastro de Livros

## Descrição

Este programa em C++ organiza informações de livros, como título e autor, em estruturas simples para armazenamento e exibição.

---
## Como funciona

1. O programa define uma estrutura para representar um livro.
2. O usuário informa os dados do livro.
3. A aplicação guarda as informações em memória.
4. O programa exibe as informações cadastradas em tela.
