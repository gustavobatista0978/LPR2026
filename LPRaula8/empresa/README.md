# Sistema de Chamados

## Descrição

Este programa em C# gerencia uma lista de chamados, permitindo cadastrar solicitações, listar itens, atualizar o status e verificar estatísticas gerais do sistema.

---
## Como funciona

1. O menu principal oferece as opções de cadastro, listagem, atualização e estatísticas.
2. O usuário informa os dados do chamado, como solicitante, setor, prioridade e descrição.
3. Os chamados são armazenados em um vetor e podem ter o status atualizado.
4. O programa exibe relatórios com a situação dos chamados cadastrados.
