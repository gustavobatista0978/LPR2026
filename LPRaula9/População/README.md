# Cálculo de População

## Descrição

Este programa em C# trabalha com dados de população e realiza operações de leitura, armazenamento e apresentação de valores relacionados ao crescimento ou comparação de populações.

---
## Como funciona

1. O usuário informa os dados que serão processados pelo programa.
2. As informações são armazenadas em variáveis ou estruturas apropriadas.
3. O código realiza os cálculos ou a organização necessária.
4. O resultado final é exibido na tela de forma clara.
