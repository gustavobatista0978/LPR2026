# Geração de Número Aleatório

## Descrição

Este programa em C++ gera e exibe um valor aleatório, demonstrando o uso da geração de números pseudoaleatórios em C++.

---
## Como funciona

1. O programa inclui as bibliotecas necessárias para geração aleatória.
2. A função rand() ou outra estratégia semelhante é utilizada.
3. O valor gerado é processado para apresentação na tela.
4. O resultado final mostra o número aleatório gerado.
