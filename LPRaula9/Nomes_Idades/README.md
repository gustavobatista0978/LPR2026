# Cadastro de Nomes e Idades

## Descrição

Este programa em C# lê nomes e idades de pessoas e organiza essas informações para serem exibidas em tela.

---
## Como funciona

1. O usuário informa os dados de cada pessoa.
2. Os valores são armazenados em variáveis ou estruturas.
3. O programa percorre os dados e os apresenta de forma organizada.
4. O resultado mostra os nomes e as idades cadastradas.
