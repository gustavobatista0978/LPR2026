# Cadastro de Piloto

## Descrição

Este programa em C++ registra informações relacionadas a um piloto, como nome e dados de desempenho, e organiza as entradas em estruturas simples.

---
## Como funciona

1. O programa define os atributos necessários para representar um piloto.
2. O usuário informa os dados do corredor.
3. Os valores são armazenados e manipulados em memória.
4. O programa mostra os dados cadastrados ao final da execução.
