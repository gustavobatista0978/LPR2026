# Cadastro de Livros

## Descrição

Este programa em C++ armazena dados de livros e organiza as informações para apresentação em tela.

---
## Como funciona

1. O programa define os atributos principais de um livro.
2. Os dados são lidos e armazenados em memória.
3. O código percorre os registros e exibe os valores cadastrados.
4. O resultado final mostra a lista de livros no terminal.
