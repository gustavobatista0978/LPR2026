# Cadastro de Nome

## Descrição

Este programa em C# lê um nome do usuário e pratica a manipulação de strings, exibindo o valor informado em uma saída simples.

---
## Como funciona

1. O programa solicita um nome ao usuário.
2. A entrada é armazenada em uma variável do tipo string.
3. A aplicação processa essa informação de forma básica.
4. O nome informado é exibido na tela.
