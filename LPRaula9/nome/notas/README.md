# Cálculo de Notas do Aluno

## Descrição

Este programa em C# trabalha com informações de aluno, como nome e notas, e calcula o resultado final com base nos valores informados.

---
## Como funciona

1. O programa lê o nome do aluno e as notas de cada avaliação.
2. Os valores são armazenados em variáveis apropriadas.
3. A média ou a situação do aluno é calculada pela lógica do programa.
4. O resultado final é exibido na tela.
