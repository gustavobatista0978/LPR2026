# Cálculo da Média Aritmética

## Descrição

Este programa em C++ calcula a média aritmética de uma quantidade de números informada pelo usuário.

O usuário define quantos números deseja inserir, e o programa soma todos os valores digitados para calcular a média.

Depois disso, o resultado é exibido com 2 casas decimais.

---
## Como funciona

1. O programa pede ao usuário a quantidade de números que serão informados.

2. É criada uma variável para armazenar a soma dos valores digitados.

3. O programa utiliza um laço `for` para repetir a entrada dos números.

4. Cada número digitado é somado à variável sum.

5. Após o término do laço, a média aritmética é calculada dividindo a soma pela quantidade de números.

6. O resultado é formatado com `2 casas decimais`.

7. A média é mostrada na tela.
