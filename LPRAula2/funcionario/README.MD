# Cálculo de Salário do Funcionário

## Descrição

Este programa em C# calcula o salário de um funcionário com base no número de horas trabalhadas e no valor recebido por hora.

O usuário informa o número do funcionário, a quantidade de horas trabalhadas e o valor pago por hora.

Depois disso, o programa calcula o salário total e exibe o resultado formatado com 2 casas decimais.

---
## Como funciona

1. O programa pede ao usuário o número do funcionário.

2. O usuário informa a quantidade de horas trabalhadas.

3. O usuário informa o valor recebido por hora.

4. O programa multiplica as horas trabalhadas pelo valor por hora.

5. O salário total é calculado.

6. O resultado é mostrado na tela formatado com 2 casas decimais.
