# Cálculo da Diferença entre Produtos

## Descrição

Este programa em C++ calcula a diferença entre o produto de dois pares de números inteiros informados pelo usuário.

O usuário digita 4 valores inteiros, e o programa utiliza a operação matemática:

(A × B) - (C × D)

Depois disso, o resultado da diferença é exibido na tela.

---
## Como funciona

1. O programa pede ao usuário 4 valores inteiros.

2. Os valores digitados são armazenados nas variáveis `a`, `b`, `c` e `d`.

3. O programa multiplica `a × b`.

4. O programa multiplica `c × d`.

5. A diferença entre os dois resultados é calculada.

6. O resultado é mostrado na tela.
