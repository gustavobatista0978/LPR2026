# Cálculo da Área do Círculo

## Descrição

Este programa em C++ calcula a área de um círculo com base no valor do raio informado pelo usuário.

O usuário digita o raio, e o programa utiliza a fórmula matemática da área do círculo.

Depois disso, o resultado é exibido com 4 casas decimais.
---
## Como funciona

1. O programa pede ao usuário o valor do raio.

2. O valor digitado é armazenado em uma variável.

3. É definida a constante `PI = 3.14159`.

4. O cálculo da área é realizado.

5. O resultado é mostrado na tela formatado com 4 casas decimais.
