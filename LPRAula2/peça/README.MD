# Cálculo do Valor Total de Peças

## Descrição

Este programa em C# calcula o valor total a pagar por duas peças diferentes com base na quantidade e no valor unitário de cada uma.

O usuário informa o código, a quantidade e o valor unitário das duas peças.

Depois disso, o programa calcula o valor total da compra e exibe o resultado formatado com 2 casas decimais.

---
## Como funciona

1. O programa pede ao usuário o código da primeira peça.

2. O usuário informa a quantidade de peças da primeira unidade.

3. O usuário informa o valor unitario da primeira peça.

4. O programa pede as mesmas informações para a segunda peça.

5. O valor total de cada peça é calculado multiplicando a quantidade pelo valor unitário.

6. Os valores das duas peças são somados.

7. O resultado é mostrado na tela formatado com 2 casas decimais.
